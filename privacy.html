Privacy Policy

Last updated: October 28, 2026

Telvin 101 YouTube Tool ("the app") is a private application used only by its owner, Veysel Karani Tekgöz, to access data of his own YouTube channel.

Data accessed

With the user's consent through Google OAuth, the app reads YouTube channel data, video metadata, analytics and reporting data via the YouTube Data API v3, YouTube Analytics API and YouTube Reporting API.

Use of data

Data is used only to display and analyze the owner's own channel performance. It is not sold, shared with third parties or used for advertising.

Storage

Data and OAuth tokens are stored only on the owner's own devices or servers. No data is collected from other users.

Revoking access

Access can be revoked at any time at https://myaccount.google.com/permissions.

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. It also uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.
